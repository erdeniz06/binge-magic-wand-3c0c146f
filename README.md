The app should remain minimal, fast and mobile-first, avoiding complex status systems. Users only have two main states: Watchlist for shows they want to watch and Watched/Library for shows they have started or watched. There are no Watching, Completed, On Hold or Dropped statuses. The main navigation consists of Films, BingeWatch, Lists and Profile, with the Journal section removed. The Home screen serves as the main discovery hub and features 100 Greatest Shows, a curated collection inspired by IMDb's Top 100 television series, and 25 Essential Classics, a country-specific collection that adapts to the user's selected country and highlights culturally significant local series. Additional sections include Popular This Week and Popular From Friends. A colorful floating AI assistant button with a magic wand icon should appear near the bottom-right corner of the Home screen, slightly above the navigation bar. This AI assistant understands the user's watch history, watchlist, ratings, favorite genres, favorite countries and viewing habits, providing personalized recommendations and answering entertainment-related questions. Search should function as both a search and discovery experience, allowing users to find TV series, actors and directors while filtering by genre, language and country of origin. Main genres are Drama, Comedy, Thriller, Romance, Sci-Fi, Crime, Horror, Documentary and Animation, with additional genres grouped under a More section. Language and Country filters should remain separate because a show's production country and spoken language can differ. The Profile page is not intended to be a traditional social media profile but rather a taste profile that showcases statistics, viewing habits, favorite genres, favorite countries, lists, ratings and overall viewing identity. BingeWatch replaces the traditional review system with an Instagram-like social layer designed specifically for TV series. Users can create posts, like content and leave comments, but discussions are episode-based and only accessible after the user has watched the relevant episode. This creates a naturally spoiler-safe environment where users can only participate in discussions for content they have already seen.
